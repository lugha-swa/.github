# Lugha-swa

Shirika la programu za lugha ya Kiswahili, Afrika ya Mashariki.

## Miradi

### Swa

Lugha ya kupanga ya mifumo yenye sintaksia kamili ya Kiswahili.
Mkusanyaji wa kujikusanya: msomaji, mchanganuzi, mkaguzi na kizalishe
vyote vimeandikwa kwa Swa yenyewe. Mnyororo wa bootstrap unajifunga
kabisa — kutoka baiti za mkono hadi fixpoint sawa kwa baiti, bila
gcc, ld, clang wala libc.

Hazina: lugha-swa/swa

Tovuti: lugha-swa.github.io

### Hati

- vipimo-vya-lugha.md — vipimo rasmi vya lugha
- uthibitisho-wa-lugha.md — rekodi ya uzingatiaji iliyopimwa

## Kanuni

Kila mchango uko kwa Kiswahili. Mabadiliko huingia kupitia PR pekee.
Program inakusanywa kwa usahihi au inakataliwa kwa sauti — jibu baya
la kimya halikubaliki kamwe.
